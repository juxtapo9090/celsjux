The problem

People on Reddit complain that the reliable TV-remote apps are subscriptions and the free ones are full of ads. A friend and I wondered: how hard is it to build a clean one?

What I built

  • Proved it first in Python with an existing library, then rebuilt it in pure Dart with no networking packages: the secure connection, the handshake and the message format written by hand (~170 lines).
  • A Flutter app on top: D-pad, OK, back, home, volume, power, YouTube and Netflix buttons. It keeps the link alive and reconnects when you come back to it.
  • Built and installed on my phone; the TV answers with its own name in the handshake.

Walls I hit

◆ my VPN ate the living room

The app timed out connecting to the TV (errno 110). My phone's VPN was set to route all traffic — including the home network — through the tunnel, so the TV was unreachable from two metres away.

VPN off → connected instantly. The proper fix is split tunnelling, or the app telling the user what's wrong.

◆ a build that never let go

The first Android build ran past my shell's timeout; the orphaned build daemon kept a lock file, and every next build hung. Killed the stale process and moved long builds to the background.

Status

  • Working prototype on my own TV and phone (2026-10-14) — 48.3 MB release build.
  • Not released. Next: first-time pairing with the TV's PIN in Dart, then finding TVs on the network automatically.
  • The test build carries my own pairing identity, so it never leaves my phone.
