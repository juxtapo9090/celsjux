The problem

I'm in a developer guild (Kracked Devs). When I'm outside, newcomers post questions in guild chat — and the site only notifies you if the site is open. Messages went unanswered. I wanted a pager: someone talks, my phone buzzes.

What I built

  • An Android app that wraps the guild site and adds the pager on top: a full client first, with notifications built in.
  • A small Rust hub server that keeps one live connection to the guild's database and turns every new message into a push notification.
  • Notifications grouped per guild with the sender's name and avatar; raid alerts with Join raid / Not this time buttons.
  • The hub holds the login refresh token; the phone only gets short-lived access.

Walls I hit

◆ the phone killed my app

The first night, a test message sent at 02:00 never arrived. The connection went silent for three minutes. The first real notification landed at 02:15:40 — then the app froze again.

The phone's battery manager freezes background apps (do_freezer_trap), even with every battery setting unlocked. Asking users to pin the app would be a burden on them, so I didn't. I moved to Firebase push, which the phone respects.

◆ Google blocked login

Google refuses sign-in inside an app's web view (disallowed_useragent). The fixes that needed the guild site to change a setting were dead ends.

Fix: open login in a Chrome Custom Tab and catch the site's callback back in the app. Logcat: 08:27:03 custom tab → 08:27:04 callback back (code=true).

Status

  • Google Play closed test since 2026-10-08 — published about 29 minutes after review started.
  • Latest build v0.6.6 (2026-10-09) fixes a Play security flag: the app now only opens guild links over https.
